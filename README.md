# 个人简介与作品集

暖黄色与黑色的响应式个人网站，适合在面试时展示个人介绍、项目和经历。

## 本地查看

直接打开 `index.html`，或在此目录启动任意静态文件服务器。无构建步骤、无安装依赖。

## GitHub Pages

在仓库 Settings → Pages 中，选择 Deploy from a branch，选择发布分支和 `/(root)`，保存。发布成功后，通过 Pages 页面给出的网址访问。

## 更新内容

- `index.html`：页面结构、经历与静态文案。
- `app.js`：默认个人资料和项目内容。
- `style.css`：样式与响应式布局。

右上角「编辑资料」仅在当前浏览器保存修改。要让所有访客看到同一份更新，需要将真实资料写入源文件并提交到仓库；也可以把编辑后的「导出网站」HTML 作为 `index.html` 上传。

当前姓名、岗位、经历和项目为占位或概念示例，正式使用前请替换。字体联网时从 Google Fonts 加载，离线时使用系统字体。
