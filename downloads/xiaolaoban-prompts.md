- **主体+动作**：林姐走回银灰车旁，回身以普通拍照姿势拍下远处瓜摊，随后坐进驾驶位，把手机放到支架上，拇指点击发送；手机屏幕只保留无字灰绿色占位，懂车帝 UI 后期合成。
- **场景与环境**：先对应 ENV-07，动作自然进入 ENV-08 车内。
- **视觉风格**：暖黄旧纪实 CRT，车内真实自然光，非内饰广告。
- **运镜或切镜**：这是一个连续镜头：35mm 从车外侧后方跟两步，林姐坐入车内后停在半开的车门外，以 50mm 视觉感看手机支架；不做屏幕大特写。

- **表演微相**：爷爷说“回家”时避开男孩目光，像怕承认自己撑不住；男孩数瓜时嘴唇无声计算，说到医药时手指停在最后一只瓜上。

### V06-B｜“哪个是小老板”｜时长框选 6–7 秒

- **运镜或切镜**：35mm 中景横移半步，从陈哥找到男孩，再停在男孩举手动作。
- **表演微相**：陈哥故意把男孩当正常老板对待，语气爽快不过分热情；男孩举手时眼睛亮起来，胸口重新挺直。

# 伍、生成批次与连续性建议

1. **先锁场景**：优先生成 ENV-01、ENV-02、ENV-03、ENV-07、ENV-09、ENV-10、ENV-12 七张主场景，选定后固定 seed；其他空镜由主场景派生。
2. **再锁人物**：CH-01、CH-02、CH-03 必须先完成正视近景和三视图；CH-04、CH-05可作为次级群像资产。
3. **按光线分三批生成**：
   - 上午暖黄：V01-A～V02-D；
   - 正午中性偏冷：V03-A～V04-C；
   - 傍晚暖灰至暖黄回升：V05-A～V07-D。
4. **西瓜数量连续**：开场满车 → V05 剩 7–8 个 → V06-C 快速减少 → V07-A 只剩 1 个 → V07-D 空车斗。
5. **汗渍连续**：男孩上午轻汗，正午额头和后背汗渍增加，傍晚汗干后衣领留下自然盐渍；不得忽有忽无。
6. **表演弧光连续**：
   - V01：装成熟、带机灵；
   - V02：第一次压住儿童欲望；
   - V03：嘴硬保护家庭；
   - V04：被看见但没有被戳破；
   - V05：第一次承认疲惫；
   - V06：恢复小老板身份；
   - V07：重新露出孩子气。
7. **声音建议**：先生成无声或弱环境声画面，后期统一对白、环境声和音乐；钢琴只在 V07-C 才进入，前面不提前催泪。
8. **懂车帝处理**：手机 UI 和片尾标识一律后期合成，视频模型只生成自然持机、点击发送和车主随口提及的表演，避免乱码与硬广感。
